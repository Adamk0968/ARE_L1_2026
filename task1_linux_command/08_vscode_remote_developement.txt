QUESTION 1: activer le serveur SSH :-->> sudo raspi-config, puis choisir interface et SSH Enable
Puis on connecte le pc et la rpi en ethernet
l'adresse de la rpi est 192.168.0.10

QUESTION 2: Après avoir installer l'extension "Remote SSH", on tape la commande Ctrl+Shift+P, puis Remote-SSH: Add New SSH Host. Pour ajouter la rpi en tant qu'hôte on entre la commande suivante: groupe7are@192.168.0.10
Enfin on choisit le premier fichier de configuration(par défaut)

Pour se connecter on tape la commandes Ctrl+Shift+P et Remote-SSH: Connect to Host… .
Ensuite on click sur  l'adresse IP de notre Rpi, puis on se connecte grâce au mot de passe.
Une fois terminé, le nom de l'hôte s'affiche en bas à gauche en bleu : SSH: [192.168.0.10].

Après avoir créer un fichier nommé test_rpi.py, on copie et exécute le script suivant : 
		import os
		import platform
		print(f"Connecté à : {platform.node()}")
		print(f"Système d'exploitation : {platform.system()}")
		print(f"Architecture : {platform.machine()}")


Pour exécuter dans le terminale :-->>> python3 test_rpi.py

Ce code permet d'afficher le nom de la machine (Rasberry pi), l'OS (Linux) et l'architecture (Debian..)
